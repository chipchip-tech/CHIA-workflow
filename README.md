# CHIA-workflow

Ghi chú và script để chạy [CHIA](https://github.com/ucb-bar/chia) (framework co-design phần cứng/phần mềm dùng agent AI, UC Berkeley) cùng Chipyard.

- [docs/setup-bazzite.md](docs/setup-bazzite.md): hướng dẫn cài đặt trên Bazzite (Docker qua bazzite-dx, SSH, conda/`chia_env`, image CHIA, Hello World, agent AI, Chipyard native trong distrobox).
- [scripts/check-bazzite-env.sh](scripts/check-bazzite-env.sh): kiểm tra nhanh máy đã sẵn sàng chạy `chia up` hay chưa (chỉ đọc, không sửa hệ thống).
